Bobox — UI overhaul

A full rebuild of the interface of my file-sharing app: from 2023 Material UI defaults to a custom shadcn/Tailwind design system — same backend, new everything else.

React + Tailwind + shadcn/ui Light & dark mode Mobile-first (390px ✓) In-app file previews New logo ~40% lighter bundle Fully responsive

Login — first impression

Same navy, same layout idea, but the new card is calmer: real tabs, inline icons, a proper Google button, and a design that breathes on phones.

Sign up

The old form crams six fields in a plain white box. The new one adds password strength feedback, labelled inputs, and a friendly switch.

File browser — the heart of the app

Rows with colour-coded icons, per-item menus, a sticky thumb-reach action bar on phones, and a friendly empty state.

File browser — desktop

Calm column, search up top, sort and filter in reach. No theme fights, no MUI defaults.

Uploads

From a bare file input to a drag-and-drop zone with live progress, cancel, and one-tap public links.

In-app previews (new feature)

Images, video, audio, PDFs and text files now open inside Bobox — with a Download button. The old app only previewed images on their info page.

Account page

The old page crashed on open (a one-line router bug from 2023). The new one shows an avatar, storage usage, and a clean logout.

404

From two silent lines of text to a real page that gets you home.
